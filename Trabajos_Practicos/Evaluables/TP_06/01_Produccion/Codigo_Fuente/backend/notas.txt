Comando:
python -m pytest tests/ -v
------------------------------------------------------
Ejecuta los test

******************************************************************************************


******************************************************************************************
Comando:
python -m pytest --cov=app --cov-report=term-missing
------------------------------------------------------
Muestra el porcentaje del código se ejecutó durante los tests.
Stmts	Cantidad de líneas de código ejecutables del archivo
Miss	Cuántas de esas líneas no se ejecutaron en ningún test
Cover	Porcentaje cubierto
Missing	Números de las líneas sin cubrir

Libreria: pip install pytest-cov
******************************************************************************************
