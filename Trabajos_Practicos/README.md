# Trabajos prácticos

Cada trabajo práctico evaluable se registra en un directorio `TP_<NN>_<Tema>/` y conserva esta estructura interna:

- `00_Enunciado/`: consigna, guía, aclaraciones y material base provisto por la cátedra.
- `01_Produccion/`: documentos de trabajo elaborados por el grupo; `Codigo_Fuente/` se utiliza solo cuando corresponde.
- `02_Entrega/`: versión final presentada.
- `03_Retroalimentacion/`: correcciones y devoluciones recibidas.
- `04_Evidencias_Repositorio/`: evidencia de commits, actualizaciones, tags y líneas base.

La estructura se preserva aun cuando alguna carpeta no contenga artefactos todavía, para asegurar uniformidad y escalabilidad.
